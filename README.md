# Noctivo Privacy Policy

Static privacy policy for the Noctivo Android video player by ForgeGamesStudio.

- Russian: `index.html`
- English: `en.html`
- Contact: forgegamesstudio@gmail.com
- No build step, JavaScript, external fonts, analytics or cookies.

GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

Expected public URL after successful deployment:
https://forgegamesstudio.github.io/Noctivo_Privacy_Policy/

Use the published HTTPS page URL in Google Play Console, not a GitHub source file
or raw-file URL. Also link to the policy from within the app. Keep the policy and
Google Play Data safety declarations aligned with the actual released app.

Open index.html locally to preview. Update both languages when behavior changes.
